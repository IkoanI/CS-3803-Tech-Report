Recommendations

To address the navigation and discoverability issues[cite: 62], we recommend overhauling the Units page to feature a grid layout. This redesign minimizes scrolling, making it significantly more desktop-friendly[cite: 177]. By displaying multiple units simultaneously in a structured grid, users can view their curriculum at a glance without extensive vertical navigation.

We strongly recommend integrating English translations directly into the unit titles and navigation elements[cite: 178]. This drastically reduces the cognitive load for beginners. Additionally, adding accuracy metrics (star ratings and percentages) directly to the unit cards allows users to evaluate their mastery quickly without navigating to a separate progress page[cite: 179].

To resolve fragmented study workflows, the Study Options page should be redesigned to include clear, distinct icons for Flashcards, Vocabulary Games, Grammar Games, and Listening Games[cite: 194]. This visual differentiation helps users quickly scan and select their desired activity[cite: 195].

The flashcard system must be updated to a Quizlet-style scrollable design[cite: 272]. By placing the flashcards in a centralized, easily navigable carousel with highly visible functional buttons, users can review vocabulary with significantly less error.

Finally, we recommend replacing the open-ended feedback box with a structured submission form[cite: 274]. This new form collects detailed information such as Name, Email, Feedback Type, and Overall Experience Rating, enabling faster developer response through proper issue categorization[cite: 274].

Conclusion

This usability study underscores the critical intersection between user interface design and educational efficacy. We learned that while gamification can successfully drive user motivation [cite: 277], its benefits are easily negated by technical friction, such as case-sensitive inputs [cite: 277] or convoluted navigation[cite: 62]. By grounding our redesign in concrete user testing data, we have transformed a frustrating experience into a streamlined, accessible learning environment that caters to absolute beginners and advancing students alike.

Engineering Hand-off: For seamless implementation of this design, the engineering team should prioritize updating the input validation logic on the backend to be case-insensitive, and integrate a virtual Korean keyboard API for the game modules. The grid layouts and structured feedback forms outlined in our Figma prototypes rely on standard CSS Flexbox/Grid and basic REST API endpoints, ensuring a straightforward technical lift without requiring a massive architectural overhaul.
